Driver Platform Credentials

Driver Note regarding B2B Platform Access: Otoqi, Driiveme, and ONLOGIST provide public REST API keys to enterprise fleet clients (car manufacturers, leasing companies, dealerships). For independent freelance drivers, assignments and missions are handled directly within their official mobile driver applications. The keys below are only required if you have enterprise fleet API access or a private automation webhook. Otherwise, leave them blank and the app will generate optimal mission chains and direct launcher links to your driver apps.

Otoqi Otoqi Driver Partner API

Obtain your key in the Otoqi Driver Portal under Account > Developer / Fleet Partner Access.

Driiveme Driiveme Pro Jockey API

Find your credentials in the Driiveme Pro Jockey Dashboard under Fleet Management > API.

Onlogist Onlogist Partner Order API

Request key via Onlogist Portal > B2B Partner API Section.

OSRM uses OpenStreetMap road data and does not require any paid key. Google Maps is only needed if you want official Google Directions.
