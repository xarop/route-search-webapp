How to use OptiRoute BCN Pro

Instructions

  1. Add missions manually or import JSON offers.
  2. Filter by platform, destination, min net profit, max duration.
  3. Use Chain trips to combine missions.
  4. Use Route planner to find multi-leg routes.
  5. Track your day with the checklist.
  6. Configure API access in Config.
