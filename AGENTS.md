# Agents

This repository contains two static web applications.

## Files
- `index.html`, `app.js`, `styles.css`: route finder using OSRM/OpenStreetMap.
- `OptiRoute-BCN-Pro.html`: single-file driver app.
- `README.md`, `DESIGN.md`, `humans.txt`.

## Guidelines
- Keep UI minimal and aligned with DESIGN.md.
- Do not expose real credentials; use local storage for API config.
- Prefer vanilla JS, no build step.
- All user-facing text should be English (multilingual via Google Translate widget).
- Sign as "Developed in Barcelona by xarop.com".
